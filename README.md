# 📚 学习工具箱（Study Box）

离线可用的课程学习工具箱 —— 把 **思维导图、章节刷题、间隔记忆卡、每日打卡、课表** 收进一个文件，手机/电脑随便用。

> 数据全部保存在本机浏览器（localStorage），不上传任何服务器；可整个文件夹离线部署。

## ✨ 功能

| 板块 | 说明 |
|---|---|
| 🧭 思维导图 | 100+ 主题树形知识脉络（药理学 · 药物化学 · 诊断学 · 医院药学），标注教材页码与高频考点⭐ |
| 🧠 章节刷题 | 400+ 道单选题，按书籍+章节芯片、错题本、收藏、模拟考 |
| 🃏 间隔记忆卡 | 100+ 组"词条→要点"卡，认识/忘记双向、间隔重复 |
| 📅 每日打卡 | 今日任务清单 + 按教学周的推荐章节（药理学/药物化学/诊断学/医院药学） |
| 🎧 六级听力 | 精选听力资源与精听技巧 |

## 📦 使用方式

### 方式 A：单文件（最简单）
直接用浏览器打开 `学习工具箱.html` 即可，或部署到任意静态服务器 / Vercel / Gitee Pages / GitHub Pages。

### 方式 B：PWA（可离线安装为 App）
`studybox-tool/` 是完整 PWA 源码（含 manifest + service worker）。部署到任意 HTTPS 静态托管后，手机浏览器"添加到主屏幕"即可当作 App 用（离线可用）。

### 方式 C：Android APK（可选）
`App源码/MainActivity.java` 是一个最小 WebView 壳（加载 APP 内置的 index.html），配合 Android SDK 可打出安装包；`构建脚本/` 提供了打包参考。预编译 APK 见仓库 Releases。

## 🔧 自定义内容

- `学习工具箱.html` 顶部的 `MIND`（思维导图）、`BANK`（题库）、`DECKS`（记忆卡）、`WEEKMAP`（每周推荐）都是普通 JS 数据结构，直接改即可。
- 我用本仓库的脚本 `mind-gen.cjs` / `merge.cjs` 批量生成这些结构（脚本见 `scripts/` 与项目文档），可复用。

## 🔒 隐私

- 全部数据存本机 localStorage，**无任何联网上报**。
- 仓库不含任何个人信息、密钥、证书（签名 `.jks`、vercel token 等一律排除）。
- 内容为 AI 辅助整理的课程学习笔记，仅供参考，版权归相应教材出版社及作者。
